# Aprender-A-Programar

Materiais e editor para aprender HTML/CSS/JS.

## Stack

- HTML
- CSS
- JavaScript

## Estrutura

- `index.html` — índice
- `html.html`, `CSS.html` — lições
- `editor.html` — editor de código
- `script.js`, `editoe.js`, `style.css`, `editor.css` — lógica e estilos
